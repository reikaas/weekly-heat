# Weekly Heat

Static site for Robin Eikaas — weekly house & techno editorial digs (12 tracks with why-it-matters + YouTube links).

Dark club aesthetic, compact track list (rank, Artist — Title, label · lane, one-line blurb, play icon). Plain static HTML generated by `build.py` from `data/weeks.json`. Works from `file://` and offline once loaded (YouTube links open externally).

## Open locally

1. Unzip `weekly-heat-site.zip` (or use this folder).
2. Open `index.html` in a browser (double-click, or drag onto Chrome/Firefox/Safari).

That’s it. No server required.

## GitHub Pages

1. Create a repo (e.g. `weekly-heat`) and push the contents of this folder to the root (or a `docs/` folder).
2. **Settings → Pages → Build and deployment**
3. Source: **Deploy from a branch** → choose `main` (or `docs` if you used that folder) → Save.
4. Site URL appears after a minute or two.

## Netlify

1. Go to [Netlify Drop](https://app.netlify.com/drop) (or Sites → Add new site → Deploy manually).
2. Drag and drop this folder (or the unzipped zip).
3. Done — you’ll get a `*.netlify.app` URL; custom domain optional.

## Cloudflare Pages

1. Cloudflare dashboard → **Workers & Pages → Create → Pages**.
2. **Upload assets** → drag this folder (or connect a Git repo pointing at it).
3. Deploy. Custom domain optional under Custom domains.

## What’s inside

```
index.html              # latest dig (home) + "Previous weeks"
archive.html            # every week, newest first (top-3 teaser, track count)
week/YYYY-MM-DD.html    # per-week pages
assets/styles.css
assets/site.js          # year + j/k keyboard nav between play links
data/weeks.json         # source of truth: all weeks + tracks
build.py                # generator: weeks.json -> index/week/archive HTML
.nojekyll               # tells GitHub Pages to serve files as-is
README.md
```

## Adding a new week (Fridays)

1. Add a new week object to `data/weeks.json` (same shape as the existing ones: `id`/`date` as `YYYY-MM-DD`, `label`, `scene`, `sourcesNote`, `tracks[]` with `rank`, `artists`, `title`, `label`, `lane`, `blurb`, `youtube`). The newest `date` is treated as the latest week automatically.
2. Run `python3 build.py` (Python 3 standard library only). It regenerates `index.html`, every `week/*.html` and `archive.html`.
3. Commit and push. Don’t hand-edit the generated HTML; edit `build.py` or `assets/` instead.
